# OpenWorld VPN — Admin Dashboard

Web-based admin dashboard used by operators to manage users, subscriptions, and VPN
servers.

## Structure

```
admin/
├── src/       # Application source code
├── public/    # Static public assets (favicon, index.html, etc.)
└── package.json
```

## Status

This is a placeholder scaffold. No real admin functionality has been implemented yet.

## Getting Started (future work)

1. Install [Node.js](https://nodejs.org/) (LTS).
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the local development server.

## Environment Variables

Copy `.env.example` to `.env` and fill in the values for your local environment.
