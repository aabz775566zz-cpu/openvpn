# OpenWorld VPN — Mobile App

Flutter application used by end users to connect to the OpenWorld VPN service.

## Structure

```
mobile/
├── lib/        # Application source code (screens, widgets, services)
├── assets/     # Images, fonts, and other static assets
└── pubspec.yaml
```

## Status

This is a placeholder scaffold. No real VPN connection logic has been implemented yet.

## Getting Started (future work)

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run` to launch the app on a simulator/device.

## Environment Variables

Copy `.env.example` to `.env` and fill in the values for your local environment.
